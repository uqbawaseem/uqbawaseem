# Personal portfolio

Live website: https://muhammad-uqba-waseem.snowyloom5.chatgpt.site

A static personal portfolio for Muhammad Uqba Waseem. Includes HTML, CSS, JavaScript and public project preview images reused from the existing DostCode portfolio.

## Run locally

From this directory:

```sh
python3 -m http.server 8000
```

Open http://localhost:8000. No build step is required. Fonts load from Google Fonts; system fonts are used when unavailable.

Professional project references describe contributions to employer or client-owned products. No proprietary application source is included. The webhook lab is a separate independent demo.

Motion respects reduced-motion preferences; card tilt is limited to fine-pointer devices.
